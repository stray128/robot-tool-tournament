# Attribution

This page lists every third-party asset that the renders, replays, web assets and print
packs use, with its licence, its full credit line and what we changed. The site's credits
page shows the same lines; `NOTICE` and the README carry them too.

Our own code is Apache-2.0. Files generated by the tools (finger STLs, GLBs of our own
geometry, replays) are released as described in `NOTICE`.

## How credit travels

| Where | What it carries |
|---|---|
| This file, `NOTICE`, README, the site's credits page | the full credit lines below |
| `assets/gripper/so_arm_102/SOURCE.md` | the full credit, the pinned commit and file hashes |
| Asset manifest entries and replay v2 headers (`attribution`) | the short credit, which names the licence, says "modified" and points at the credits page anchor (`/credits#gripper`, `/credits#gso`) |
| Each GLB file (`asset.copyright`, `asset.extras`) | the same short credit, plus the licence, role and changes; the web export's meshopt compression keeps both, and checks it did |
| A v2 print pack's `ATTRIBUTION.txt` | the full gripper credit (the carriage block is drawn from its dimensions) |
| Burned-in video and still captions | nothing third-party: they say "simulation replay · MuJoCo · run … · design …" |
| Video end card | "Gripper CAD: an open-source parallel gripper (CC BY 4.0, modified). Scanned objects: Google Scanned Objects (CC BY 4.0, modified)." |

On screen the gripper is always called "an open-source parallel gripper". `tests/test_gvr.py`
checks that the maker is named only in the files above and the vendored provenance in
`assets/gripper/so_arm_102/`, and that no burned-in caption carries a third-party credit;
`web/scripts/smoke_v2.mjs` checks the same on the rendered bout page.

## Gripper: simulation meshes (CC BY 4.0)

**Credit:** Robonine, SO-ARM 102, https://github.com/roboninecom/SO-ARM-102, CC BY 4.0.

**Copyright notice (as supplied upstream):** Copyright (c) 2026 Robonine.

- **Source:** commit `190eb162c9e59d7f6dceab850ea1b5c6a4539c14`, files
  `simulation/urdf/meshes/link5_1.stl` (frame), `clamp1_1.stl` (left clamp) and
  `clamp2_1.stl` (right clamp). They are vendored unmodified in
  `assets/gripper/so_arm_102/meshes/` with the licence text, and pinned by sha256 in
  `assets/gripper/so_arm_102/lock.json`.
- **Licence:** the upstream licence map (`LICENSING.md` and `REUSE.toml` at the pinned
  commit) puts everything under `simulation/` under
  CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). The licence text is in
  `assets/gripper/so_arm_102/LICENSE-CC-BY-4.0.txt`.
- **Modified:** cut at the jaw root plane into carriage and blade; re-posed into the
  simulator's palm and jaw frames (and the right clamp moved 1.0 mm so the jaws are
  symmetric); simplified into convex collision pieces for the stock finger (CoACD
  threshold 0.02, seed 0, at most 40 pieces); re-encoded as GLB.
- **Short credit (assets, replays):** `An open-source parallel gripper, CC BY 4.0, modified
  (full credit: /credits#gripper)`.

## Scanned objects: Google Scanned Objects (CC BY 4.0)

**Credit:** Google Scanned Objects by Google Research (Downs et al., ICRA 2022), CC BY 4.0;
MuJoCo models by Kevin Zakka, kevinzakka/mujoco_scanned_objects at commit `6ff8d275`
(scans CC BY 4.0, MJCF XML MIT).

- **Used for:** held-out real objects, props and at most one hero shot. Only objects marked
  `brand_visible: false` appear in hero shots and videos; the site's held-out gallery uses
  untextured (clay) renders.
- **Modified:** convex decomposition for collision (CoACD 0.02, seed 0); re-posed into the
  object frame; textures re-encoded (WebP) and meshes simplified to 50% for the web;
  re-encoded as GLB.
- **Short credit (assets, replays):** `Google Scanned Objects, CC BY 4.0, modified (full
  credit: /credits#gso)`.

# Example parts

Four generic shop-floor parts for trying "Bring Your Part" and for the `rtt.part` tests.
Each is a single watertight solid, written as a binary STL in millimetres.

| File | Part | Size (mm) |
|---|---|---|
| `l_bracket.stl` | angle bracket, 4 mm wall, inside fillet, two 5.5 mm holes | 60 x 30 x 50 |
| `spur_gear.stl` | 20-tooth module 2.5 gear blank, 8 mm bore | 55 x 55 x 10 |
| `rounded_tub.stl` | open-top container, 8 mm corner radii, 2.5 mm wall | 70 x 50 x 40 |
| `dumbbell_handle.stl` | 16 mm bar between two 40 mm discs | 84 x 40 x 40 |

They are modelled procedurally by `src/rtt/part/examples.py` (manifold3d booleans) and
regenerated byte for byte with:

```bash
python -m rtt.part.examples            # writes assets/parts/*.stl
```

`tests/test_part_intake.py` checks that these files match the generator.
